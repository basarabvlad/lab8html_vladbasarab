Лабораторна робота №7

Тема: Розробка динамічних елементів вебсайтів з використанням JavaScript-сценаріїв.

1. Обробка подій головного вікна

У цьому розділі демонструється обробка подій браузера та виведення повідомлень про їх виникнення.

Деякі події залежать від підтримки браузера. Для застарілих подій використано сучасні аналоги.

2. Обробка подій елементів сторінки

Наведи курсор, натисни або перетягни текст, щоб перевірити роботу обробників подій миші.

Натисни або перетягни цей заголовок

Це текстовий елемент для перевірки подій onclick, ondblclick, onmousedown, onmouseup, onmouseover, onmouseout та інших.

Перетягни сюди заголовок або текст

Область для перевірки події прокручування. Прокручуй цей блок вниз та вгору.

JavaScript дозволяє реагувати на дії користувача та змінювати стиль елементів сторінки.

Подія scroll виникає під час прокручування вмісту цього блоку.

Це додатковий текст для створення прокручування.

Кінець області прокручування.

Журнал подій елементів

3. Історія звернень до сторінок

Після натискання кнопки Run Task буде виведено історію відвідування сторінок сайту ComputerZone.

4. Обробка подій миші для зображень

Наведи курсор на зображення або натисни на нього, щоб побачити зміну оформлення.

5. Пошук інформації за допомогою регулярних виразів

Введи текст та натисни кнопку пошуку. Програма знайде слова, які починаються з літери «е» та закінчуються літерою «а», порахує кількість слів, цифр та цілих чисел.

Результати пошуку з'являться тут.

6. Обробка одновимірного масиву

Задано одновимірний масив A розміру N. Необхідно знайти серед усіх від'ємних елементів максимальний елемент та його індекс.
