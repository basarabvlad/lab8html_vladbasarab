Лабораторна робота №6

Тема: Основи SVG. Проєктування веб-документів за допомогою графічних об'єктів.

1. Статичне зображення — варіант №2

За допомогою SVG побудовано графічне зображення відповідно до другого варіанта методичних вказівок. Малюнок складається з геометричних фігур, розташованих відносно координатних осей X та Y.

2. Розташування тексту по кривій

Для розміщення тексту вздовж кривої використано елементи path та textPath. Текст розташовується відповідно до форми заданої кривої.

3. Динамічна зміна графічних фігур

За допомогою SVG-анімації реалізовано п'ять видів динамічних змін геометричних фігур. Для цього використовуються елементи animate та animateTransform.

Анімація виконується автоматично та повторюється безперервно. Кожна фігура демонструє окремий тип динамічної трансформації.

4. Способи підключення SVG до HTML

Для демонстрації способів вбудовування SVG-графіки використано теги object, param, embed, noembed та iframe.
